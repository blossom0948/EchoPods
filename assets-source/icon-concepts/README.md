# EchoPods icon concepts

The four initial generated concept sheets contain 20 app-icon directions (five per sheet, numbered by reading left to right). They are retained as previews, not production launcher assets. Their generated earbud shapes were inconsistent, so do not use them as the source for the final mark.

1. `echopods-icon-concepts-01-case-pair.png` — earbud pair and case compositions.
2. `echopods-icon-concepts-02-widget-glyphs.png` — compact widget-style earbud, case, and ring glyphs.
3. `echopods-icon-concepts-03-echo-motifs.png` — earbud/case marks combined with echo waves.
4. `echopods-icon-concepts-04-flat-marks.png` — flatter geometric silhouettes and negative-space ideas.

Each sheet's concepts are read from the leftmost tile (1) to the rightmost tile (5). The older initial concept sheets remain previews only.

## Flat 2D redraw

`echopods-icon-concepts-v2-flat.svg` is a 20-option contact sheet built from the app's existing left/right widget earbud silhouettes and a compact flat case glyph. The latest revision uses one fixed, enlarged, symmetrical composition in every tile: matched left/right earbuds above a centered case. Only the palette and a restrained ring/echo accent vary, so the product stays large and consistently aligned instead of jumping between unrelated layouts. No photorealistic or 3D product model is intended.

Read the numbered concepts left to right, top to bottom. `echopods-icon-concepts-v2-flat-preview.png` is the raster contact sheet. Individual 557×557 PNGs are in `flat-v2/`, named `echopods-icon-01.png` through `echopods-icon-20.png`. The revised set is also bundled as `echopods-icon-options-flat-v2-rebalanced.zip`.

Concept **20** is the user's temporary selected EchoPods mark. The app launcher vector is `app/src/main/res/drawable/ic_app_icon.xml`; the 512×512 Play listing export is `assets-source/play-store/echopods-icon-512.png`. The Play export is a size conversion of concept 20, not a separate redesign. A final feature graphic and real-device Play listing screenshots are still required.
