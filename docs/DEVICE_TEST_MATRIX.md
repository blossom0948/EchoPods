# Device test matrix

실기기 검증 기록입니다. 배터리 위젯은 기기에서 받은 값을 사용하며, AirPods 패킷이 없을 때 임의 배터리를 만들지 않습니다.

## Galaxy Z Fold4 (SM-F936N, Android 16 / API 36)

확인일: 2026-11-16. 기기는 USB 연결 상태였고 AirPods는 연결되어 있지 않았습니다.

| 확인 항목 | 결과 | 범위 |
|---|---|---|
| EchoPods 업데이트 설치 | 통과 | v0.6.3-debug (version code 56) 설치 및 실행 확인. AirPods가 연결되지 않은 상태에서 설정 화면을 확인함 |
| Echo Health 별도 설치·실행 | 통과 | 같은 서명으로 설치, EchoPods Labs 진입점에서 앱 실행 확인 |
| 외관·대화 인지 복귀 설정 | 통과 | iOS 외관 유지, 팝업 크기 선택과 10초–2분 복귀 슬라이더 표시·저장 확인 |
| 신기능 안내·iOS 마침 동작 | 통과 | 제공된 iPhone 목업에 실제 앱 화면을 합성하고 확대 컷 표시 확인. 마지막 안내의 원형 손잡이와 밀어서 계속하기 화면 확인 |
| 배터리 위젯 | 통과 | One UI 홈의 2×2 인스턴스가 네 칸 그리드로 표시됨. 기기에서 보고된 값은 없음 |
| 청취 모드 위젯 | 통과 | 위젯 선택기에서 추가 가능, 홈 화면에서 선택 모드 표시 확인. AirPods 명령 전송은 미검증 |
| Labs 메뉴와 위젯 선택 화면 | 통과 | 실제 Fold4 화면에서 열고 배치 확인 |
| v0.6.3 설정·실험실 화면 | 통과 | iOS 외관에서 긴 설명 정렬, 실험실 카드 겹침, 헤더 비침과 복귀 화면 확인 |
| 아일랜드 크기 슬라이더·실제 미리보기 | 통과 | SMALL/MEDIUM/LARGE 크기 적용 및 설정 화면 상단 오버레이 반영 확인. 이어버드 배터리 데이터는 없음 |
| 설정→실험실 화면 전환 | 통과 | 실제 Fold4에서 진입·복귀 화면을 캡처해 확인. Labs 화면은 불투명한 배경으로 이전 설정 글자 비침을 막고, 미리보기 오버레이는 이동 전에 닫힘. 화면 전환은 240ms |
| 앱 충돌 / ANR 로그 | 미발견 | 이번 조작 후 최근 logcat 5,000줄에서 EchoPods의 FATAL EXCEPTION/ANR 없음 |
| 펼침·접힘 레이아웃 | 미검증 | 두 화면 크기 상태를 모두 촬영해 비교하지 않음 |
| AACP 고급 제어, 팝업·착용 감지·미디어 일시정지 | 미검증 | AirPods가 연결되지 않아 실측 불가 |
| Pro 3 심박수 | 미검증 | Pro 3 실물이 없어 센서 패킷과 운동 중 실시간 수신을 검증할 수 없음 |

## 다른 Galaxy / Android 버전

아직 실기기 검증 전입니다. Android 12(API 31) 이상에서 설치 가능하도록 설정되어 있으나, AACP 고급 제어와 센서 기능은 Bluetooth 칩셋·OS 빌드·이어버드 펌웨어에 따라 달라집니다. 설치 가능 여부를 모든 고급 기능의 호환성으로 해석하면 안 됩니다.
